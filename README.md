# 보험소 — 소비자 직접 선택 · 광고 노출 구독

기존 네이비 디자인, 회원가입, 지도·전문가 목록, 상담 일정·후기·관리자 기능을 유지합니다.
소비자가 전문가를 직접 선택하며 자동 재배정은 없습니다. 상담 요청·확정·완료·취소는 결제와 독립적입니다.

## 광고 구독
- 베이직 / 프리미엄 / 지역독점 광고 슬롯의 기간제 선불 결제입니다.
- 초기 요금·기간·약정 노출수는 공란이며 판매 비활성입니다. 테스트 조건은 테스트 fixture에만 있습니다.
- 매 기간 직접 결제합니다. 카드 저장·자동 갱신·자동 청구는 구현하지 않았습니다.
- 계약 시 금액·기간·약정 노출수를 고정합니다. 새 요금제는 새 주문에만 적용됩니다.
- 광고와 일반 전문가 목록을 구분합니다. 지역독점은 동일 지역의 지역독점 광고 슬롯에만 적용하며 일반 목록을 숨기지 않습니다.
- 기간 종료 후 약정 노출 미달과 플랫폼 귀책 근거를 관리자가 확인한 경우 테스트 전액 환불을 처리합니다. 상담 수는 가격·환불 계산에 사용하지 않습니다.
- 카드·간편결제 위젯은 test_gck_/test_gsk_ 키 한 쌍을 사용합니다. 실제 지원 수단은 테스트 상점별로 검증해야 합니다.

## 실행
Node 22 이상과 Microsoft Edge가 필요합니다.
- npm ci
- npm run verify — 빌드, DB/결제 검증, 가입 회귀, 360px/PC 흐름
- node scripts/preview.mjs — 정적 화면 미리보기, 실제 가입·결제 연결 없음
- npm run preflight — 설정 검사
- npm run smoke — 설정된 테스트 서비스 연결 검사
- npm run concurrency — 별도 로컬 PostgreSQL에 일회용 DB를 생성하여 독점 광고 슬롯·상담 시간 경합 검사

## DB 적용
현재 SQL은 새 빈 테스트 DB용입니다. 001~006 순서 또는 supabase/_apply_all.sql을 적용합니다.
기존 003/004 적용 DB에는 재실행하지 마세요. 기존 거래 이관·보존 계획과 별도 전환 마이그레이션이 필요합니다.
supabase/_verify_after_apply.sql은 신규 객체와 접근권한을 확인합니다.

## 주요 화면
- /, /find.html: 홈, 지도, 직접 선택 목록, 기본 비활성 광고 영역
- /requests.html: 고객 일정·완료 확인·후기·신고
- /partner-work.html: 설계사 상담 업무 및 별도 광고 구독
- /admin-requests.html: 상담 검토, 광고 조건·슬롯·노출·환불·감사 이력
- /signup.html, /login.html, /reset-password.html: 기존 Supabase 인증
- /analysis.html, /dashboard.html: 샘플 체험

## 현재 제한
공개 사이트의 Supabase 인증 설정·공개 목록 연결은 확인했습니다. 실제 이메일 인증·OAuth 왕복·역할 권한·토스 테스트 상점·외부 웹훅과 운영 부하 검증은 미완료입니다.
노출은 표시 이벤트 기준이며 실인원이나 부정 조회 제거를 보증하지 않습니다. 운영 전 봇·반복 조회 방어 및 정책 검토가 필요합니다.
공개 사이트가 존재하며, 이번 로컬 수정은 배포하지 않았습니다. 실결제·운영 정보 검증은 수행하지 않았습니다. 상세 상태는 docs/final-report.md, 설정은 docs/setup.md를 확인하세요.
