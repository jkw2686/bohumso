계정과 상담 정보

계정 관리에 이메일, 인증 식별자·상태, 표시명, 가입일, 동의 버전·시각·선택 여부를 사용합니다. Google 로그인 시 공급자가 전달한 계정 정보를 처리하며 비밀번호는 인증 서비스가 처리합니다. 상담·예약에는 회원 식별자, 상담 유형, 지역, 선택 또는 배정된 전문가·거점, 희망 날짜·시간, 요청 상태, 생성일, 변경·취소 이력을 저장합니다.

오픈 알림 신청

오픈 알림 신청: 지역, 휴대전화, 선택한 도움 유형, 동의 기록. 일반 방문자는 해당 지역의 서비스 오픈·준비 관련 안내에, 전문가는 해당 지역의 서비스 오픈·활동 준비 관련 안내에 사용합니다. 지역별 관심 규모와 활동 희망 전문가 규모는 다음 오픈 지역의 우선순위를 판단하기 위한 집계로만 확인합니다. 신청일부터 최대 1년 보관하고 기간 경과 또는 동의 철회 시 파기합니다. 기존 1회 안내에만 동의한 신청은 그 범위를 유지하며 안내 후 파기합니다. 개별 신청자의 연락처와 신청 내용은 다른 사용자나 전문가에게 제공하지 않습니다.

휴대전화 확인

상담·예약을 위한 번호 확인 단계에서 휴대전화번호와 인증 처리 상태를 사용합니다. Supabase 인증과 SOLAPI 문자 발송을 통해 인증번호를 전달하고 확인합니다. 인증번호 발송은 상담 연락처 제공 동의와 별개입니다. 전문가에게 제공할 때에는 별도 동의를 받습니다.

전문가 정보와 확인자료

전문가의 이름, 소속, 주활동지역, 추가 지역, 전문분야, 상담 가능 요일·시간, 심사 상태를 처리합니다. 등록증 또는 위촉·소속 증명서의 이름·소속·등록번호·유효기간과 심사 기록을 확인합니다. 파일 접수가 제공되는 경우 JPEG·PNG·PDF, 최대 4MB를 비공개 저장하며 본인은 제출 내역 확인·삭제를, 권한 있는 관리자는 심사를 위해 원본 열람을 할 수 있습니다. 신분증·주민등록번호·의료서류는 제출하지 마세요.

위치와 브라우저 저장

브라우저에서 허용한 기기 좌표, 네트워크 접속지역 추정, 직접 선택한 지역을 구분하여 주변 탐색에 사용합니다. 지도 탐색의 최근 위치는 같은 탭에서 최대 15분 재사용하며 만료 후 조회하거나 탭을 닫으면 제거됩니다. 인증 세션은 브라우저 저장소, 로그인 복귀 경로는 탭 저장소에 저장합니다. 상시·백그라운드 추적은 하지 않습니다. 거부해도 직접 지역 선택이 가능합니다.

제3자 제공

상담 확정 화면에서 제공받는 전문가, 예약 일정 연락과 요청한 상담이라는 목적, 이름·확인된 휴대전화라는 항목, 상담 종료 또는 취소 시까지라는 이용기간을 안내하고 동의를 받습니다. 분쟁이 접수된 경우 해당 해결에 필요한 범위에서 처리 종료까지 보관합니다. 동의를 거부하면 연락처를 전달하지 않고 상담 확정이 제한됩니다. 목록 조회만으로 연락처를 제공하지 않습니다. 긴급 요청은 별도 동의 후 후보에게 최소 정보를, 수락한 담당자에게 필요한 장소·연락처를 제공합니다.

외부 서비스

Netlify는 웹 호스팅·서버 기능, Supabase는 인증·데이터베이스·비공개 파일 저장, Google은 선택한 소셜 로그인, OpenStreetMap은 지도, SOLAPI는 인증 문자 발송에 사용됩니다. 요청 처리 과정에서 공급자에게 IP·기기·요청 정보가 전달될 수 있고 지도 제공자에게는 표시 영역 요청이 전달됩니다. 각 공급자의 처리 범위는 서비스 제공과 보안 운영에 필요한 범위로 제한합니다.

보유와 파기

일반 계정정보는 회원 탈퇴 등 이용 목적 달성 시 지체 없이 파기합니다. 상담·예약 정보는 상담 종료 또는 취소 후 후속 문의·분쟁 처리를 위해 1년 보관합니다. 동의 증빙과 전문가 심사 기록은 회원 탈퇴 또는 전문가 활동 종료 후 1년 보관합니다. 확인자료 원본은 심사 완료 후 30일 이내 파기하며 심사 전 삭제 요청도 받습니다. 분쟁이 진행 중이거나 법령상 별도 보존 의무가 있는 경우 필요한 항목만 분리 보관하고 목적 달성 시 파기합니다. 이 기간은 서비스 내부 운영 정책이며 법정 보존기간을 뜻하지 않습니다. 운영팀이 보유기간과 삭제 요청을 확인해 DB와 저장 파일을 처리합니다.

긴급 요청의 보유

긴급 요청 좌표는 도착·완료·취소·만료 처리 시 정리합니다. 4시간 처리 창이 끝난 뒤 24시간이 지난 요청의 연락처·장소와 1년이 지난 활동지역 변경 이력은 정리 대상입니다.

권리와 보호조치

내 정보와 고객지원에서 열람·정정·삭제·탈퇴·동의 철회를 요청할 수 있습니다. 본인 확인 후 처리하며 별도 보관이 필요한 경우 사유를 설명합니다. 만 14세 미만 가입은 받지 않습니다. 인증·역할 검사·행 단위 접근제어와 비공개 파일 접근 제한을 사용합니다. 앱 오류 수집에 전체 연락처·건강정보·문서내용·비밀키를 넣지 않습니다. 카드정보를 받지 않습니다.
