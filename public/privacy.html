이용약관개인정보처리방침기존 회원 로그인

현재는 비공개 베타 준비 단계입니다. 새로운 가입 완료와 예약 요청은 정책·초대·인증 조건을 확인한 뒤 개방합니다. 기존 회원은 로그인해 본인의 이력을 확인할 수 있습니다.

1. 어떤 정보를 사용하는가요?

  • 계정 확인: 이메일, 인증 계정 식별자와 인증 상태. Google 로그인에서는 인증 공급자가 전달하는 계정 정보를 사용합니다. 이메일 비밀번호는 인증 서비스에서 처리하며 운영 화면에 표시하지 않습니다.
  • 회원 관리: 가입 시각, 필수 동의 버전·시각, 선택 마케팅 동의 여부. 선택 동의는 필수가 아닙니다.
  • 예약: 상담 목적, 지역, 희망 일정, 배정·수락·변경 상태. 연락처와 장소는 요청·동의 흐름에서 필요한 범위로 처리합니다.
  • 긴급 상담: 요청 지역, 목적, 장소, 연락처, 짧은 메모와 진행 상태. 병명 세부 기록, 진료 서류, 주민등록번호 등 불필요한 정보를 입력하지 마세요.
  • 전문가: 이름, 직군, 소속, 자격·심사 정보, 활동지역, 소비자보호 서약, 심사·제재 기록. 승인되지 않은 전문가를 실제 전문가 목록에 표시하지 않습니다.

2. 위치와 브라우저 저장

홈과 지도는 권한을 허용한 경우 기기 위치를 확인합니다. 기기 위치, 접속 지역 추정, 직접 선택한 지역을 구분해 표시합니다. 접속 지역 추정은 GPS가 아닙니다.

최근 위치는 같은 탭에서 최대 15분 재사용하며 일반 회원 프로필에 저장하지 않습니다. 지도 타일을 불러올 때 지도 제공자에게 IP와 표시 영역에 관한 요청이 전달될 수 있습니다. 배경에서 계속 위치를 추적하지 않습니다.

전문가가 ‘지금 가능’을 켜면 동의한 기간의 일회성 위치를 서버에서 사용합니다. 중지·만료·수락 시 좌표를 정리하며 공개 목록에는 정확한 위치를 내보내지 않습니다.

로그인 유지용 인증 세션은 브라우저 저장소에, 가입 후 돌아갈 화면은 탭 저장소에 저장합니다. 공용 기기에서는 이용 후 로그아웃하세요.

3. 누가 볼 수 있나요?

일반 예약 연락처는 고객이 확인·동의한 해당 담당자에게 상태에 따라 제공되며 운영자는 예약 관리와 분쟁 처리에 필요한 범위에서 확인합니다. 긴급 요청 후보에게는 지역·목적 등 개략 정보가 표시되고, 수락한 담당자에게 장소·연락처·메모가 제공됩니다. 고객 정보를 판매하지 않습니다.

Netlify는 사이트·서버 기능, Supabase는 인증·데이터 저장, Google은 선택한 소셜 로그인, OpenStreetMap은 지도 표시에 사용합니다. 위탁 관계, 저장 국가, 국외 이전 항목·시점·방법·보유기간 및 거부 방법은 계약과 운영 조건 확인 후 정식 문서에 반영합니다.

4. 얼마나 보관하나요?

  • 탭의 지도 위치: 최대 15분.
  • 긴급 요청 좌표: 도착·완료·취소·만료 시 정리.
  • 긴급 요청과 연결된 제안·이벤트: 요청의 4시간 처리 창 종료 후 24시간이 지나면 정리 작업에서 삭제.
  • 전문가 활동지역 변경 이력: 1년이 지난 항목 정리.
  • 일반 계정·예약·심사·감사 기록과 공급자 로그: 최종 보유기간과 삭제 절차를 검토 중입니다. 전체 계정 자동삭제 기능이 제공되는 상태는 아닙니다.

5. 열람·정정·삭제 요청

아래 문의 이메일로 요청해 주세요. 비밀번호·인증번호·신분증 원본은 보내지 마세요. 본인 확인에 필요한 최소 정보와 처리 범위를 별도로 안내하고, 보관 사유가 있는 자료는 그 사유와 처리 결과를 설명합니다. 일괄 삭제 완료를 미리 보장하지 않습니다.

6. 아직 사용하지 않는 기능

실제 SMS 발송, 실결제, 카드 저장, 전문가 파일 업로드는 현재 꺼져 있습니다. 준비된 테스트 코드는 실제 서비스 개방을 의미하지 않습니다. 전화 인증번호를 앱에 따로 저장하지 않습니다. 방문 통계 수집도 현재 꺼져 있으며 호스팅·인증 서비스의 운영 로그와 구분합니다.

7. 보호 조치와 변경

로그인과 서버 권한 검사, 데이터별 접근 제한, 비공개 저장 구조를 사용합니다. 운영자 정보·보유기간·외부 처리 조건을 확정하면 공개 전 안내를 갱신하고 필요한 동의를 받습니다.
