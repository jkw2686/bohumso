# 전체 메뉴 화면 · 2026-10-12

## 범위
- 최신 범위 정정에 따라 별도 `/menu.html`만 구성. 기존 홈·지도·예약·고객센터 탭 위치는 유지하고 마지막 ‘내 정보’를 ‘메뉴’로 연결.
- 원래 내 계정 페이지는 계정 설정으로 유지. 전문가 전체 메뉴를 소비자 화면에 적용하지 않음.
- 운영 main `1900e5d`에서 분리한 `codex/expert-navigation`. 다른 작업본·미배포 DB 변경·기존 문서 전용 커밋은 포함하지 않음.
- 운영 DB, 가격, 가입 조건, 심사/상담/공개 상태의 저장 의미, 외부 발송은 변경하지 않음.

## 화면과 연결
- 상단: 실제 이름·역할, 기본 아바타 또는 기존 사진, 계정 설정, 공개 목록에서 확인된 본인 프로필 보기.
- 전문가: 상담 관리 / 내 활동 / 업무 자료 / 이용 안내. 서버가 관리자라고 확인한 경우에만 운영 관리 추가.
- 비회원·소비자: 전문가/보험소 탐색·내 예약·고객센터·계정 설정. 로그인 복귀 주소에 메뉴를 허용하되 기존 외부 주소 차단 유지.
- 프로필·상담 설정은 기존 접힌 폼을 펼치고 해당 제목으로 이동. 활동 지역·지금 방문·예약 필터·실천·자료도 기존 화면으로 이동.
- 브라우저 뒤로가기로 메뉴 복귀. 복귀 시 서버 회원 상태를 다시 확인하며 이전 역할의 링크를 남기지 않음.
- 별도 지도 공개 스위치, 보험소 관리 페이지, 공지사항 목록은 현재 운영 코드에 없어 추가하지 않음. 기존 승인·상담 가능 설정을 임의로 지도 ON/OFF 기능으로 바꾸지 않음.

## 디자인
- 새 색상은 `.menu-page`에만 적용. 배경 `#F6F7F9`, 표면 흰색, 강조 `#3157C8`. 로고·Pretendard·기존 SVG 아이콘 체계와 간격 토큰 재사용.
- 제목 24px, 행 이름 16px, 보조 14px. 행 전체 링크·48px 이상 터치, 내용에 따라 높이 확장.
- 프로필 1영역과 기능 분류 4영역. 메뉴마다 별도 카드나 반복 설명을 만들지 않음.
- 본문·보조·강조·아이콘의 실제 조합 대비 4.5:1 이상 확인.

## 검증
- `node scripts/build.mjs`: 성공. 기존 설치 의존성 사용, 신규 설치 없음.
- `node --test --test-name-pattern='return path' tests/member-gate.test.mjs`: 외부 주소·인증 반복 이동 차단 통과.
- `tests/menu-browser.mjs`: 실제 HTML/번들과 격리 PGlite RPC를 사용. 운영 계정/고객 데이터/문자/결제에 접근하지 않음. 인증 세션은 가상 계정으로 모의 처리.
- 360·390·430·1440px: 가로 넘침 없음, 메뉴 48px 이상, 마지막 행 하단 탭에 가리지 않음. 360px의 긴 이름 및 본문 200% 확대 확인.
- 자동 브라우저가 간헐적으로 종료되거나 캡처에 실패해 화면 검증과 연결 검증을 나눔. 캡처된 화면은 `artifacts/menu-screens/`. 연결만 재실행: `node --liftoff-only --no-wasm-tier-up --wasm-num-compilation-tasks=1 tests/menu-browser.mjs --flows-only`.
- 연결 검사 15항목 통과: 역할별 메뉴, 프로필·상담 설정 펼침, 활동 지역·방문 설정, 예약 요청 필터, 성장 자료·실천, 뒤로가기, 부분 실패 및 회원 조회 실패 복구, 브라우저 예외 없음. `full-menu-screens/results.json`에 결과 보존.
- 격리 fixture에 없는 `my_phone_status` 및 구버전 예약 이력 조회는 기존 오류 처리를 거쳐 진행되었으며 해당 기능은 이 검사에서 검증하지 않음. 메뉴 진입·현재 설정·자료 이동은 실제 기존 RPC 응답으로 확인.
- 실제 휴대전화 OS 키보드·글자 크기 설정, 운영 계정의 저장 작업은 미확인. 이번 수정은 기존 저장 코드에 변경 없음.
