# 비공개 통합 흐름 — 2026-09-27

## 실행과 범위
- 시작: npm run dev:test-flow (프로젝트 루트).
- 최신 통합 화면: http://127.0.0.1:3195/
- 전문가: /expert, 관리자: /admin, 소비자 신청 내역: /requests.html.
- 상단 테스트 계정 전환으로 역할을 바꾼다. 별도 브라우저 세션에서는 각각 독립 역할을 유지한다.
- 3193/pro는 기존 PRO 미리보기이며 이번 통합 테스트 주소가 아니다. 기존 화면·공개 사이트를 배포하거나 덮어쓰지 않았다.
- 기존 UI 컴포넌트·색상 토큰·이미지 압축·거리 정렬 함수를 재사용한다.

## 실제 연결된 데이터 흐름
1. 소비자가 홈 → 상황 → 임시 지도 → 전문가 선택 → 방문 방식 → 동의 후 신청한다.
2. 신청은 로컬 PostgreSQL 호환 DB(PGlite)에 저장되고 관리자 접수 목록에 표시된다. 닫힌 상세 화면에서는 2초마다 변경을 확인한다. 편집 중에는 입력 보호를 위해 자동 갱신을 보류한다.
3. 관리자가 신규/전달함/완료를 기록하면 소비자 내 신청 화면에 반영된다. 문자나 전문가 자동 배분은 실행하지 않는다.
4. 새 가상 전문가: 손해사정사/설계사 → 이름·소속·지역 → 서류 선택 사항 → 필수 서약 → 미인증.
5. 프로필에서 등록번호 입력·가상 서류 두 종류 첨부 → 심사 요청 → 관리자 서류 열람·사유·확인 후 승인하면 지도에 표시된다.
6. 보완 요청/거절과 사유·담당자·시각은 DB 이력에 남는다. 경고 시 뱃지 회수, 노출정지/제명 시 지도 숨김. 제명 후에도 본인의 첨부서류 삭제는 가능하다.
7. 공개 목록에 서류/등록번호를 내보내지 않는다. 순서는 거리 → 평점 → 전문분야이다.

## 저장과 테스트 제한
- DB 위치: artifacts/test-flow-db (Git 제외). 서버 재시작 후 DB 기록은 보존된다.
- 가상 역할 세션은 서버 메모리에 있다. 서버 재시작 시 역할은 소비자로 초기화되며 새로 만든 전문가 세션 복구 로그인은 아직 없다. 저장된 신청·전문가 기록은 관리자에서 조회된다.
- 서류는 가상 자료만 사용한다. JPG/PNG는 기존 압축 함수를 사용한다. 서버에서 파일 형식/크기 검사, 관리자만 원본 열람, 신청자 본인 삭제를 지원한다.
- 실제 휴대폰 본인인증/실회원 로그인/법적 자격 검증이 아니다. 테스트 계정 전환은 인증 서비스가 아니다.
- 지도는 API 키 없는 임시 좌표 배치이다. 실제 도로·길찾기·실제 전문가 주소와 일치하지 않는다. 미개설 지역은 개설 예정으로 표시한다.
- 공개 배포, 실결제, 자동 발송은 OFF. 이전 공개 사이트의 동작 변경이나 운영 준비 완료를 의미하지 않는다.

## Supabase 연결 준비와 미완료 부분
실제 테스트 Supabase 프로젝트 연결은 아직 완료되지 않았다. 로컬 DB 검증을 원격 Supabase 검증으로 표현하지 않는다.

별도 테스트 프로젝트에 supabase/012_private_test_flow.sql만 적용하고 서버 환경변수를 설정한다:
- TEST_SUPABASE_URL: 전용 테스트 프로젝트 HTTPS 주소
- TEST_SUPABASE_PROJECT_REF: 그 프로젝트 식별자
- TEST_SUPABASE_SERVICE_ROLE_KEY: 서버 전용 키 (채팅/소스/브라우저에 넣지 않음)
- TEST_SUPABASE_ALLOW_REMOTE: true

기존 운영 프로젝트는 코드에서 차단한다. 키가 없으면 로컬 DB를 사용하고 상단에 원격 미연결을 표시한다. 설정이 잘못되면 조용히 다른 DB로 대체하지 않고 시작을 실패시킨다. 원격 SQL은 자동 적용하지 않는다.
이 스키마는 가상 계정 전용이다. RPC는 service_role만 실행하고 anon/authenticated의 직접 권한을 명시적으로 회수한다. 이 역할 선택 서버를 인터넷에 노출하지 않는다.

## 검증 명령
- npm run test:connected: DB/권한/재시작 보존 + Edge 브라우저의 소비자/전문가/관리자 전체 흐름.
- npm run build: 기존 프로덕션 클라이언트·함수 및 통합 테스트 클라이언트 빌드. 테스트 번들은 artifacts에만 생성.
- npm run verify: 기존 회귀 검사에 통합 브라우저 검사를 추가.
