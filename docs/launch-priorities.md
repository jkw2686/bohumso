# 실제 가입·운영 전환 우선순위
기준: 2026-09-14 Netlify 배포본과 다운로드된 bohumso-redesign.zip.
새 디자인은 유지하고 Netlify를 사용한다. 과거 Sites 배포본에 덮어쓰지 않는다.

1. 가입·로그인·권한: 이메일 인증, 고객 가입 동의, 로그아웃, 고객/파트너/관리자 분리. 공개 알림 서비스로 개인정보 전송 제거.
2. 파트너 운영: 설계사/손해사정사/변호사/기업보험 컨설턴트/세무사/거점 운영자 신청, 자격·소속 확인, 승인/반려/정지, 승인 이력.
3. 상담·방문: 본인 요청 조회, 단일 담당자 배정, 일정 요청/확정/취소/완료. 고객 동의 및 예약 확정 전 전문가에게 연락처 제공하지 않기. 화면에서만 숨기지 말고 DB 접근 제어 필요.
4. 업무 화면: 고객 내 요청, 전문가 내 일정·배정 업무, 관리자 접수·파트너·거점. 승인된 전문가의 업무 화면은 데이터가 생길 때 연결.
5. 한 지역·소수 검증 파트너 파일럿: 정상/취소/노쇼/민원/계정 정지/삭제 요청 검증.
6. 과금·정산·통계: 실제 운영 확인 후 검토. 설계사·변호사·세무사 등의 업무·수수료 조건은 직군별 검토 후 확정.
자동 보장분석·마이데이터·민간 본인확인·서류 업로드는 후순위.
카카오 로그인은 법적 본인확인이나 자격 확인과 동일하게 취급하지 않는다.
구체 법률 검토가 완료된 것으로 간주하지 않는다.

# 현재 차단 사항
Netlify 원격 배포 권한, Supabase 프로젝트·운영 정보는 아직 연결되지 않았다.
이 단계는 로컬 구현이며 새 배포본 적용 및 실제 인증 메일·DB 권한 검증은 미완료.
기존 Netlify 공개 페이지의 알림 전송은 로컬 수정만으로 중단되지 않는다.
회원가입·승인 기능 활성화 전 데이터베이스 정책과 메일 발송 설정을 실제 환경에서 검증한다.

## 2026-09-15 진행 상태
1·2번 로컬 구현에 이어 3번 상담·방문예약과 4번의 고객 요청/전문가 배정 목록/관리자 배정 화면을 추가했다.
접수 → 단일 담당자 배정 → 고객 확인·동의 → 확정 → 완료/취소를 DB에서 통제한다. 실제 외부 계정 연결과 공개 배포는 아직 미완료다.
다음 우선순위는 Supabase 생성·연결, 운영 정보·동의 문서 확정, 기존 Netlify 계정 연결과 미리보기 배포, 실제 계정 검증이다.
이후 실제 제휴 거점 지도·예약 연결, 전문가 가용 일정, 운영 알림·보유 기간에 따른 삭제를 추가하고 한 지역에서 파일럿한다.
