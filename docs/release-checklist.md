# 배포 전 체크리스트

- [ ] 실제 운영자·사업자·문의처 확인
- [ ] 약관·개인정보·선택 전문가 연락처 제공·노출 수집·보유/삭제·환불 기준 검토
- [ ] 구독 금액·기간·약정 노출수 확정 (코드 초기값은 공란)
- [ ] 별도 Supabase 테스트 DB에 001~006 적용 및 실제 인증/역할 권한 확인
- [ ] 기존 DB가 있다면 별도 이관 계획·백업·전환 마이그레이션 검증
- [ ] 위젯용 테스트 키 연결, 상점별 카드·페이 승인/조회/환불/웹훅 검증
- [ ] 독점 슬롯·상담 시간에 대한 실제 PostgreSQL 다중 연결 검증
- [ ] 노출 계측 정책 및 봇·반복 조회 방어 검토
- [ ] 최신 전체 로컬 verify 결과 확인
- [ ] 서버 비밀키 노출 없음 및 플래그·origin 확인
- [ ] 별도 최종 배포 승인

광고 구독은 기간제 선불·수동 갱신입니다. 자동 청구가 가능한 서비스로 안내하지 않습니다.
상담 요청·완료 지표는 표시용이며 구독 가격이나 환불 계산에 사용하지 않습니다.
