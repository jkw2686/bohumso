## 검증 범위의 한계와 후속 확인

공식 자료 사실 검증이며 개별 청구에 대한 법률 판단·지급 판단을 수행하지 않았다. 로그인, 실제 신청·접수·발급, 고객정보 입력, 모든 첨부 서식 다운로드는 실행하지 않았다. 병원별 사망·미성년·대리인 요건을 다른 기관에 일반화하지 않았다. 기존 합병·계약이전 설명, 상급종합병원 지정 범위, 비대상 항목의 내용은 이번에 재검증하지 않았다.

미확인 항목의 후속 확인은 위 공식 경로를 정상 렌더링 가능한 브라우저에서 열어 상세 안내를 읽는 작업이다. 방화벽·해외 접속 제한은 우회하지 않았으며, 제한 안내의 공식 고객센터 경로를 기록했다. 과거 PDF가 검색된 사실만으로 현행 최신 서식을 대체하지 않았다.

## 수정 및 로컬 검증

수정 대상은 `public/claim-resources-data.js`와 이 문서뿐이다. Node 데이터 모듈 로드 및 assert 검사 통과: 전체 91개, detail 55·homepage 21·check 15, 11개 상태 갱신·15개 미확인 유지. 기존 26개 외 65개는 HEAD 데이터와 동일하며 이름·URL·별칭·신청인 안내·원자료 날짜가 보존됨을 확인했다. 미확인 15개는 checkNote 외 모든 필드가 기존과 동일하다. `git diff --check` 통과. 데이터·문서 변경이므로 빌드 산출물을 만드는 전체 빌드나 실제 발급·청구 시험은 실행하지 않았다.

작업 시작 시 이미 수정된 `public/help/accident.html`, `cancer.html`, `claim.html`, `coverage.html`, `death.html`, `hospitalization.html`은 이번 작업에서 수정하지 않았다. 최신 사용자 지시에 따라 HANDOFF 등 다른 문서도 변경하지 않고, 커밋·push·배포를 실행하지 않는다.

종료 시에는 `public/claim-resources.html`, `public/expert-profile-card.js`, 여러 `src/`·`tests/` 파일 및 `.role-edit*.cjs`, `src/expert-navigation.js`의 추가 변경도 작업 트리에 나타났다. 이 작업에서는 해당 파일을 쓰거나 정리하지 않았다. 작업 트리 전체가 깨끗하다고 보고하지 않으며, 이번 감사의 수정 범위는 위 두 파일로 한정한다.
