참고: https://bohumso-private-trial.jkw2686.chatgpt.site/ 에 사용자 로그인 후 실제 전문가 A 프로필→방문예약→내용 확인 화면을 확인했다. 체험 예약 저장은 누르지 않았다.

## 비교·적용
- 체험사이트: 전문가 프로필에 도움 분야/상담·방문 상태를 분리하고 예약시간 진입, 날짜·정각 버튼, 비활성 시간 취소선, 일정 확인과 수정 단계.
- 기존 보험소: 전문가·보험소 직접 선택, 7일 빠른 날짜/90일 이내 다른 날짜, 서버 가능시간, 가입·인증 복귀, 신청 후 일정 조율이 이미 구현됨. 이를 보존했다.
- 적용: 오전/오후별 시간 버튼, 한국시간·정각 안내, 불가시간 취소선과 설명, 일정 선택/내용 확인 화면 분리, 대상·일정·방식·상담내용·지역의 최종 확인, 시간 다시 선택/날짜 변경, 확인 전 전송 없음.
- 체험용 데이터, 휴무/14일 제한, 체험 1시간을 실제 상담시간으로 확약하는 문구, 무조건 무료, 가짜 자격·후기·가장 빠른 예약은 가져오지 않음. 기존 실제09~17시 정각/30분 전/90일 범위와 서버 시간·권한 검증을 유지.
- 실제 전문가 방문 즉시요청은 별도 기존 흐름이며 시간정책을 섞지 않는다. 정책·DB·가격·권한·개인정보 입력 변경 없음.
