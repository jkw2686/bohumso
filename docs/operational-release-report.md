## 실제 운영 검증 범위

대표자 기존 계정의 인증된 연락처 조건을 유지한 상태에서 SQL 트랜잭션으로 실제 상담 RPC 저장·고객 조회·취소를 검증했다. 마지막 ROLLBACK으로 예약과 알림을 남기지 않았다. 운영 전환 후 consultations=0, 설정 백업 1건 확인. 고객·전문가를 새로 만들거나 타인의 계정을 임의 사용하지 않았다.

이번 검증은 실제 Google 신규가입, SMS 수신, 다른 전문가의 수락, 실제 파일 업로드→다운로드→삭제까지 모두 완료한 E2E가 아니다. 서류 업로드 HTTP 왕복은 미검증이며 로컬 DB 권한 테스트와 운영 설정/접근 차단 검증으로 구분한다. 승인된 대표자 전문가 프로필은 업로드 잠금 조건을 변경하지 않았다.
