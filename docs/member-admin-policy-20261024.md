# 관리자·가입·개인정보 통합 기준 (2026-10-24)

이 문서는 사용자의 최신 지침이다. 기존 PROJECT_BRIEF/CLAUDE/가입·개인정보 문서의 충돌하는 내용보다 우선한다. 구현 완료를 뜻하는 정책 문서가 아니며 아래 적용 상태를 별도로 확인한다.

## 가입과 연락
- 소비자/전문가를 구분하고 기존 소셜·이메일 로그인을 유지한다. 로그인한 계정에 이름·전화번호를 필수 저장한다. 이미 있는 값은 채우고 누락분만 보완한다. 재가입하지 않는다.
- 이름/번호 입력은 실명·명의 인증이 아니다. 신분증·주민번호·CI/DI를 추가 수집하지 않는다. PASS/ARS/SMS를 가입 필수로 만들지 않는다. 외부 본인확인은 후속 과제다.
- 연락처는 최초 미확인. 실제 상담 조율 통화 후 담당 전문가가 통화 확인을 기록할 수 있다. 이름 인증이 아니다. 번호 변경 시 초기화한다. 연락 불가/신청 부인/반복 장난 신청을 구별하고 자동 삭제하지 않는다.
- 번호만으로 로그인·복구·다른 계정 조회·병합하지 않는다. 같은 번호의 별도 계정을 차단하지 않는다.
- 전문가 자격 심사는 별개다. 연락처 입력으로 승인/노출 상태를 바꾸지 않는다.
- 신청자는 환자·피보험자·수익자와 다를 수 있다. 실제 지원 단계에서 필요한 관계·동의만 확인한다. 첫 통화는 신청 여부부터 확인하고, 그 전에는 진단명·보험금·가족 상황을 언급하지 않는다.

## 관리자
- 홈: 회원 현황, 기간별 상담 현황, 처리할 일 최대5건. 네 메뉴: 회원 관리/상담 관리/운영 관리/설정·보안.
- 회원은 auth 계정ID 기준 중복 없이 센다. 등록 전문가 또는 전문가 유형 선택 계정을 전문가로 분류하고 나머지를 소비자로 분류한다(상호 배타). 탈퇴/테스트 계정은 필터로 구분하며 기본 합계에 포함된다. 가입일은 회원정보 생성일, 미완료 계정은 Auth 계정 생성일. 날짜 KST.
- 응대 권한은 이름을 볼 수 있다. 목록 전화는 마스킹, 상세는 권한 검사 후 공개. 통계 전용은 집계만. 상세주소/정확한 좌표/건강정보/첨부는 기본 목록에 없다.
- 관리자 다중요소 인증(AAL2), 서버/RLS/Storage 권한, 조회·변경·다운로드 기록. 일괄 다운로드 기본 미제공. 로그에 이름/번호/진단 내용 원문을 넣지 않는다.
- 실패는 실패로 표시한다. 조회 전/실패를 정상·0명으로 처리하지 않는다.

## 기존 기능 유지
전문가 전화 연결은 고객 선택·동의→전문가 수락→그 전문가에게 연락처 공개다. 일정 재입력/앱 내 확정을 추가하지 않는다. 보험소 방문예약과 기존 이력, 역할별 화면, 사진·브랜드 문구는 유지한다.

## 적용 상태와 운영 전 확인
- 신규 SQL 079~083은 로컬 구현/격리 검증 대상이다. 운영 적용·배포 완료로 해석하지 않는다.
- 새 연락처는 탈퇴 상태 변경 시 삭제한다. 기존 상담/동의/자격자료는 임의 삭제하지 않는다. 기존 정책의 1년/30일 보관에 대한 전 시스템 자동 파기와 법정 보관 근거 검토는 별도 확인이 필요하다.
- Netlify 환경변수에서 Supabase URL/공개키/서버키 및 SMS 설정 이름 존재를 확인했다. 값은 출력하지 않았다. 로컬 Supabase 관리 토큰/설정파일이 없어 운영 Auth rate-limit, CAPTCHA, TOTP 사용 허용 설정은 확인하지 못했다. 기본값을 실제 설정으로 보고하지 않는다.
- 기존 Storage SQL은 expert-documents / expert-profile-photos 직접 접근을 제한하며 서류 endpoint는 인증 후 권한 RPC를 거친다. 운영 정책 적용 상태와 실제 파일 접근은 별도 검증 대상이다.
- 통계 전용 계정을 기존 광역 관리자에 임의로 추가하지 않는다. 권한 지정은 대표자가 실제 담당 업무를 확인한 뒤 수행한다.
- 개인정보 고지 개정과 운영 DB 변경은 같은 릴리스로 진행한다. 시행 전 현재 서비스와 다른 수집·보호 상태를 완료로 공지하지 않는다.

공식 구현 참고: [Supabase MFA](https://supabase.com/docs/guides/auth/auth-mfa), [인증 요청 제한](https://supabase.com/docs/guides/auth/rate-limits). 이 작업으로 법적 준수가 모두 확인된 것은 아니다.
