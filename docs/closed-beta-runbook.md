# 비공개 베타 실행 준비

일반 공개 전환 아님. 현재 정책 미승인·초대명단 비어 있음·실제 SMS OFF. 모의 인증·결제는 실사용 성공 증거가 아니다.

## 개방 전 순서
1. OWNER_INPUTS.md의 법적 운영자·필수 정책·문의 담당을 확인하고 최종 문서 별도 승인.
2. 별도 비공개 테스트 환경 및 참여 동의된 고객10~20명·승인 전문가3~5명 준비. 운영 DB에 가상 실명/자격 승인 넣지 않음.
3. 공급자 담당자가 SMS/SMTP 설정·비밀키 입력. 앱/서버 플래그 일치 및 실패 제한 확인. 전화 인증 우회 금지.
4. 관리자 권한으로 지정 참여자의 초대만 등록. 일반 공개 스위치를 끄는 방식으로 초대를 대신하지 않음.
5. 아래20건을 실제기기에서 실행, 증거에는 연락처·좌표·OTP·비밀키를 가림. 실패하면 해당 접수만 중지하고 원인 해결.

- Netlify 이전 ready 배포로 되돌릴 수 있다. DB를 초기화하거나 테이블을 제거해 롤백하지 않는다.
- 현재 승인된 기준 배포: 796592c / 6ac1b4ddb8fd6100087dd171 (2026-10-04 11:07 KST).
- 장애·보안 문제는 원문 개인정보 없이 오류 코드·경로·시각·역할만 기록한다.
