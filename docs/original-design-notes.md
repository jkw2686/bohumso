# 보험소 디자인 개선본

네이비·블루 첫 화면, CSS/SVG 입체 지도 그래픽, 모바일 대응, 수도권 83개 지역별 개설 예정 아이콘 및 지역 필터.
서울 25구 / 경기 일반구 24개 및 구가 없는 23개 시군 / 인천 11개 군구. 좌표는 지역 대표 위치 예시이며 실제 영업점 주소가 아닙니다.
모든 지역은 개설 예정입니다. 기존 임시 전화번호와 운영 거점 데이터를 제거했습니다.

Netlify 기존 정적 사이트 배포 폴더를 이 폴더 내용으로 교체하세요. 실제 배포는 수행하지 않았습니다.
지도와 폰트는 인터넷 연결이 필요합니다. 지도 외부 CDN 실패 시 안내문이 표시됩니다.

검증: JS 구문, HTML 로컬 링크 및 ID 중복, 지역 개수·필터·팝업 로직. 브라우저 설치 네트워크 오류로 렌더링·실기기 검수는 미완료입니다.
기존 상담 전송 방식은 유지했습니다. 실제 고객 정보 제출 테스트는 하지 않았습니다.
