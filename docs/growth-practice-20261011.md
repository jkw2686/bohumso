## 운영 전 남은 결정과 비용

- 개인 실천은 기존 계정 비활성/탈퇴 검사와 auth.users 삭제 시 cascade에 연결했다. 자발적 삭제는 본인 화면에서 가능하다. **문의 대화·개인 실천의 별도 보관 기간 및 탈퇴 요청 후 실제 삭제 처리 시점은 기존 정책에 명시되지 않아 운영자가 결정해야 한다.** 운영자가 개인 메모를 열람하는 UI는 추가하지 않았다. 기술적 DB 관리자 접근이 절대 불가능하다고 약속하지 않는다.
- 현재 새 외부 공급자 호출 0회. 호스팅/DB의 기존 사용료까지 0원이라고 판단하지 않는다. 모델 미선정, 키 미입력, 유료 연결 미승인. 자동화 활성화 없음.
- 준비 가정: 주간 원고 1개+실천 1개, 월간 책 1개. 월 4~5주라면 기본 생성 5~6회. 사용 한도 후보 월 최대 8회, 건별 재시도 최대 2회, 연속 실패 3회 중지. 허용한 공식 API/RSS/공개 페이지만 수집하고 개인 실천·고객 자료를 생성 입력으로 전달하지 않는 어댑터 구조다.
- 월 비용은 선택 모델의 입력 단가×입력 토큰 + 출력 단가×출력 토큰 + 별도 수집 서비스 비용으로 산정해야 한다. 현재 모델/원문 길이를 정하지 않아 금액을 확정하지 않았다. 공급자를 정하면 공식 단가와 상한 금액을 제시하고 비용 승인을 받아야 한다. 스케줄러와 실제 예산 제한 저장소도 활성화 전에 연결·검증한다.

## 충돌 가능 파일

`src/account.js`, `src/member-access.js`, `scripts/build.mjs`, `public/admin.html`, `.gitignore`, 인수인계 문서는 공통 파일이다. 구체적 진입/배포 항목만 수정했다. 성장 신규 파일은 독립적이다. 자료실/프로필/지도/예약/상담 상태 구현을 복사하거나 변경하지 않았다. 기존 고객센터 기반·메신저 커밋과 이번 변경을 함께 배포해야 한다.
