# 현재 구조 분석 및 이번 변경 기준
- 정적 HTML/CSS/JavaScript + esbuild, Supabase 인증/SQL RPC, Netlify Functions. 별도 프론트 프레임워크 없음.
- 홈·지도·상담·샘플 분석·진단·가입·로그인·비밀번호 재설정·내 계정·파트너 신청·관리자 승인·역할별 요청 목록 존재.
- 실제 거점은 0건, 수도권 표시는 개설 예정 지역. 카드 PG 없음. 계정 환경변수 미설정.
- 기존 예약은 관리자 배정/설계사 완료 방식. 새로운 직접선택/자동매칭·고객 완료 확인 방식과 구분해 이력을 보존한다.
- 이번 작업은 로컬 구현·테스트·빌드만. 배포·실결제·운영 메시지·운영 DB 변경 금지.
- 가격 초기값은 정책 테이블 한 곳: 완료 2건 무료, 이후 총 70,000원(VAT 포함), 35,000원씩 두 단계 직접 결제.
- 예약 확정 시 가격·정책·무료 여부 고정. 무료 슬롯은 원자적으로 배정하며 취소·확인된 노쇼 때 복원.
- 소비자 선택 설계사에게만 연락처 제공. 자동 다음후보 배정은 소비자가 자동매칭에 동의한 건에 한함.
- 기존 분석은 샘플만 유지. 구체 병명·증권·건강정보 입력/저장 기능 추가 금지.
- 첨부 전체 지침과 결제 구현 범위 차이는 사용자에게 확인 중. 테스트 PG 외 실결제는 코드에서 차단한다.
