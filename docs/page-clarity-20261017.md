## 공통 구현

- public/page-clarity.css: 기존 색/글꼴/간격 계열에 페이지 토큰 추가. 상단 16px/24px, 제목 다음 16px, 카드 16px 간격·모바일16px/PC24px 안쪽 여백. 헤더와 본문 가로 기준 통일. 지도 geometry는 기존 소유 레이아웃 유지. 빈 상태/장식 로딩 공간과 중복 하단 빈 여백 정리.
- 전문가 관리: 기존 DOM을 옮겨 이벤트와 입력을 보존한다. ON/OFF와 주 설정 → 간결한 자료/업무 메뉴 → 신청·추가 관리. 위치 사용 동의는 실제 켜기 동작에 남긴다. 조회 실패를 승인 대기로 추정하지 않는다.
- 설명: native details/summary, 제목 행 44px 이상, 키보드 Enter/Space, 여러 항목 동시 열기, 본문16px. 추가 모달이나 제한 높이 내부 스크롤 없음. 필수 동의·오류·상태·실제 비용은 접어 숨기지 않는다.
- 예약: 상세 열기와 실제 수락/확정 버튼 명칭 분리. 상담 지역·권한 있는 장소·서버 비용 안내는 요약에 남긴다. 상세 내부 일정/문의/취소와 약속 부가 화면은 inline 모드로 중첩 접힘 해소. 부가 기능 활성/정책 설정 변경 없음.

## 미수정·미검수와 한계

- policy-archive/ 아래 과거 약관 8개와 test-flow.html 개발 전용 화면은 수정하지 않았다. 과거 약관 원문·전체 실화면, 개발 역할 전환 화면은 이번 검수 범위에서 제외해 별도 미검수로 기록한다.
- 이전 서비스 주소 consult/find/analysis/dashboard/diagnosis는 위 표에서 각각 점검. netlify.toml의 /my-reservations, /reserve, /consultation/new, /pro 매핑은 기존 대상 유지(설정 소스 확인, 이번 운영 HTTP 리다이렉트 미검증).
- 실제 Android/iPhone, OS 글자 확대·키보드·스크린리더 음성, 실제 푸시 수신 미검증. 200%는 브라우저 CSS 글자 확대 검사다.
- 운영 회원의 실제 예약 처리·심사 승인·결제·고객센터 발송은 하지 않았다. 권한/서버 성공 또는 모형 검사로 실제 수신/처리 완료를 주장하지 않는다.
- 운영 배포/출시 준비 완료 미판정. 현재 운영판은 이전 배포이며 이번 로컬 변경과 구분한다.
