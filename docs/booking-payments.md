# 예약 결제 준비 상태

소비자 상담 무료 정책을 유지한다. 예시 가격은 운영 화면에 넣지 않는다.
`src/booking-payment.js`의 PaymentProvider와 카드 선택 UI, 021의 비공개 프로필·수단·암호화 빌링키 테이블은 준비 구조다. 현재 고객 화면에서는 호출하지 않는다.

기본값: BOOKING_PAYMENTS_ENABLED=false, SAVED_CARDS_ENABLED=false. 기존 광고 테스트 결제 플래그와 분리한다.

실제 활성화에는 사업자/PG 승인, 가격정책 확정, 인증된 서버의 금액 조회·승인·조회·취소·웹훅 구현 및 검증이 필요하다. 키 입력만으로 실결제가 완성되었다고 표시하면 안 된다. 기존 광고 결제 서버를 예약 과금에 자동 재사용하지 않는다.

전체 카드번호·CVC·비밀번호는 수집·저장하지 않는다. PG 안전창에서 등록하고 서버에서만 빌링키를 암호화한다. 브라우저에는 수단 ID, 카드사, 마지막 네 자리만 반환한다. 비밀 빌링키는 공개 스키마나 프런트엔드 설정에 넣지 않는다.
