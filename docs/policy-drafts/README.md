# 정책 문서 초안 (약관·개인정보)

> **상태: 초안. 게시 금지.** 법률 검토와 사업자·운영 정보 확정 전까지 공개 사이트에 게시하지 않는다.
> 라이브 `public/terms.html`·`public/privacy.html`은 "준비 중" 상태를 그대로 유지한다. 확정 후 이 초안을 해당 페이지로 이식한다.

## 구성
- `terms-draft.md` — 이용약관 초안
- `privacy-draft.md` — 개인정보 처리방침 초안 (제3자 제공·위치·후기·방문집계 포함)

## 작성 근거와 한계
- 이 초안의 **동작 서술**(수집 항목·처리 방식·시점)은 현재 구현된 코드 동작에 근거한다: 이메일 인증 계정, 설계사 심사 정보, 상담/방문 일정, 선택 설계사에게만 연락처 제공(명시 동의), 후기 공개(동의+검토), 익명 방문 집계(기본 비활성), 그리고 **수집하지 않는 항목**(주민등록번호·보험증권·건강정보·카드번호/CVC).
- `[   ]` 로 표시한 값은 **미확정 사실**이다. 임의로 채우지 않았다: 운영 사업자명·사업자등록번호·주소·대표자·개인정보 보호책임자·문의처·보유기간(일수)·연결료의 법적 성격·환불 세부기준 등. 사업자 정보 확정과 법률 검토로만 채운다.
- 이 초안은 법률 자문이 아니다. `docs/final-report.md` §11의 별도 검토 대상(연결료 업무 성격·직군별 허용 범위·광고 표현·제3자 제공·보유/삭제)을 대체하지 않는다.

## 확정 → 게시 절차
1. 사업자 정보 확정 및 법률 검토로 모든 `[   ]` 채움.
2. 상담 담당자(변호사/노무사 등 필요 시) 검토 반영.
3. 확정본을 `public/terms.html`·`public/privacy.html`에 이식(기존 디자인/스타일 유지).
4. `OPERATOR_NAME`·`PRIVACY_CONTACT` 서버 환경변수 설정, `POLICIES_APPROVED=true`.
5. `docs/release-checklist.md` 게이트 D 항목 체크.
