## 변경
- 040: 대표자 UUID/이메일 고정, 대표자 전용 관리자 추가·해제 RPC와 이력. 추가 대상은 이미 가입·이메일 확인을 완료한 활성 회원이다. 다른 관리자에게 재위임 권한을 주지 않는다. 대표자는 해제할 수 없다.
- 041: early_expert_review_before_roster의 자기 심사 차단만 대표자에 한해 예외. 자격자료, 휴대전화 확인, 소속 유효기간과 근거 검증 유지. OWNER_SELF_* 이력을 남긴다. 실제 승인 상태를 자동 변경하지 않는다.
- 관리자 화면에 대표자만 보이는 관리자 계정 관리 추가.
- 계정/예약/자격자료 삭제 없음. 권한 해제 작업의 DELETE는 admin_memberships의 권한 행만 제거한다.
