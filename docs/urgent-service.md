# 활동지역·지금 가능·긴급 요청

2026-10-04 사용자 지침을 적용한다. 이 기능의 배정 방식은 이전 문서의 직접 선택 전용 규칙을 대체한다. 연결 과금은 없다.

## 동작
- 활동지역: 설정 열기 → 위치 찾기/검색 결과 선택 → 지도 확인 → 완료, 기본 4회 클릭. 추가 2곳 선택 시 6회(입력·OS 권한 허용 제외). 변경은 동일 3단계. 변경 이력 1년 보관.
- 집계: 주활동지역만. 전화 인증·회원 이메일/약관·전문가 승인·관리자 노출 검증·활성 계정·7일 이내 지금 가능 설정 기록. 보조 지역·임시 GPS 제외. 10명 이상 “지역 서비스 오픈”; 물리 보험소 개설과 무관.
- 기본 OFF. 30분/60분/오늘 18시 KST까지. 별도 동의 후 1회 기기 GPS. 정확도 3km 이내만 접수, 접속 IP 위치로 대체하지 않음. 시간 종료·OFF·수락 시 GPS 삭제. 서버 만료 비교 즉시 제외, cron 1분 간격 물리 삭제.
- 공개 카탈로그는 임시 GPS/정확도/전화 미반환. 기존 카탈로그도 전문가 좌표 제거, 활동권역 중심좌표만 별도 명칭으로 반환. 거리 = 선택 지역 중심과의 직선거리 올림 km. 임의의 조회 좌표는 받지 않음. 도착시간은 경로 엔진이 없어 수락 후 안내, 임의 시간 보장 없음.
- 고객 요청 3단계: 상황 → 장소 → 전화·짧은 내용·동의. 요청 재시도 동일 UUID, 동시 활성 요청 1개/시간당 최대 3개. 후보는 ON·유효·검증·30km 이내. 전문분야 → 직선거리 → 7일 배정량 → 수락률 → 활동지역 순으로 상위 5명. 경로 기반 ETA 순위는 아직 미적용.
- 후보는 상황·대략 지역·올림 거리·방문 방식만 확인. 정확한 만날 장소·전화·메모는 수락자 1명에게만 제공. 요청 행 잠금 + 전문가 상태 행 잠금 + 활성 전문가 유일 인덱스. 늦은 수락 차단. 일시 중지/자격 철회 시 상세 재조회 차단.
- REQUESTED → ACCEPTED → PREPARING → DEPARTED → EN_ROUTE → ARRIVED → COMPLETED. PREPARING/EN_ROUTE는 선택 단계. 고객/전문가 취소, 15분 미수락/4시간 진행 만료 지원. 출발 버튼 없이 자동 이동 상태 없음. 화면이 보일 때 15초 조회.
- ENABLE_LIVE_LOCATION=false, ENABLE_BACKGROUND_LOCATION=false. 출발은 상태만 알림. 정확한 위치 공유 시작은 서버에서도 거절. 추후 수락된 단일 상대방·명시적 공유 동의·만료가 모두 확인되어야 별도 구현/검토 후 활성화 가능. 현재 이동경로 저장·watchPosition·Background 추적 없음.
- 도착/완료/취소/4시간 만료 시 요청 좌표 삭제. 전문가 임시 GPS는 수락 시 이미 삭제. 만날 장소·연락처·메모 포함 긴급 요청은 4시간 요청 창 종료 후 24시간 보관, 이후 삭제. 이벤트도 함께 삭제. 기존 예약 자료는 영향 없음.

## 검증
urgent-service.test.mjs: A/F 지역 변경·주지역 집계, B 만료, C 1명 수락/후속 수락 거절/권한, D 단계 전이, E 삭제, 익명/전화미인증 차단, 구형 운영 DB 호환. PGlite의 순차 트랜잭션 검증이며 독립 PostgreSQL 연결 경합 부하테스트는 별도 운영 전 검사.
urgent-browser.cjs: 가상 계정과 실제 로컬 DB RPC, 320/390/1440 화면, 3단계 설정/변경, GPS 모의, 1시간 ON, 고객 요청, 연락처 비공개→수락 공개, 출발 선택, 완료 타임라인. 실제 고객에게 요청하지 않음.

## OWNER_ACTION_REQUIRED
- 실제 전화 인증 SMS 공급자 설정·발송 점검, 승인·노출 검증된 실제 전문가와 제한된 운영 시범 필요. 테스트 계정 승인으로 대체하지 않는다.
- 개인정보처리방침/위치정보 이용 동의문·보유기간/파기방식·접근권한·감사기록 검토 및 위치기반서비스 신고 필요 여부 확인. 본 문서는 법률 판단이 아니다.
- 이동 위치공유·백그라운드 추적은 출시/법률·정책 검토 전 켜지 않는다. 현재 상태 알림만 제공.
- 활동지역은 등록된 수도권 84개 권역(기존 83+판교), 전국 검색은 별도 지역 데이터 확장 필요.
