회원가입·내 위치·지역별 거점 복원
- src/test-flow/ui.js: 회원가입 메뉴 복원, 최초 홈 위치 권한 요청, 허용 시 내 위치 중심과 가까운 지역 선택, 거부 시 수동 선택. 위치는 브라우저 메모리에만 유지.
- src/test-flow/areas.js: 기존 public/coverage.js에 있던 서울·경기·인천 83개 지역 기준점 재사용. 실제 사무실 주소가 아님.
- src/test-flow/map.js: 현재 위치 표시, 자동 범위 맞춤으로 먼 거점으로 이동하던 문제 수정.
- public/test-flow.css: 회원가입 강조 및 개설 예정 마커 구분.
- tests/location-signup-browser.mjs: 가상 송파 위치로 지도 중심/가까운 지역/수동 선택/예정 거점 예약 차단/가입 이동 검증 통과.
- 실제 3195 화면의 가입 버튼과 수동 지역 선택, 360px 가로 넘침 검사 통과. 프로덕션 빌드 통과.
기존 가상 예약 가능 거점 4곳은 유지, 나머지는 개설 예정으로 표시. 전국 모든 시군구 데이터 확장이 아니라 기존 수도권 데이터 복원이다. 공개 배포·실가입·결제 설정은 변경하지 않음.
