원복은 `supabase/rollback_profile_office_scope.sql` 후 `supabase/rollback_connection_review.sql` 순서로 준비했다. 진행 중인 일정 제안이 있으면 053 원복은 거부되며 먼저 정상 절차로 해결해야 한다. 새 테이블·기존 회원·예약·선택 값·이력은 지우지 않는다. 프론트엔드는 이 작업 커밋을 되돌려 `e08a4d5` 기준으로 복원한 후 별도 승인된 배포를 한다. 기존 운영 코드 기준은 `fb04f34`, 기존 배포는 `6ac9fdf4ca4eb500092bc4a6`이다.

## 운영지표와 후속 확인

기존 상담 이벤트·상태 변경 기록과 일정 제안/수락/거절 기록을 사용할 수 있다. 로그인 이후 선택 유지율, OFF 후 재선택 이탈, 자료실 검색 실패율·링크 복사 사용량은 현재 전용 집계가 없으므로 후속 검토 목록으로만 남긴다. 측정을 위해 고객 연락처·건강정보·위치를 새로 수집하지 않았다.
