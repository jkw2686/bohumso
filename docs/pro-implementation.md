# PRO 청구준비 로컬 MVP 구현 기록

## 실행
`node scripts/pro-preview.mjs`
설계사 화면: http://127.0.0.1:3193/pro
고객 화면: 설계사에서 요청한 뒤 표시되는 ‘고객 화면 열기 (가상)’ 링크.
실제 문자 발송·공개 배포는 하지 않음. 고객·병원은 고정된 가상 자료. 테스트 로그인 쿠키는 운영 인증이 아님.

## 구현
- 상담에서 대리발급 준비 필요를 확인한 뒤 고객·병원·필요서류·청구상황 선택.
- 고객 화면에는 병원·서류를 읽기 전용으로 표시. 이름·전화·청구상황을 다시 입력받지 않음.
- 신분증 촬영 입력과 가상 신분증 체험. 원본은 브라우저 메모리에서만 취급하고 서버에 올리지 않음.
- 마스킹은 자동 OCR이 아닌 직접 드래그·전체 가림 방식. 가상 신분증은 예시 영역을 미리 가림. 가림 결과 확인 전 완료 버튼 비활성. PNG로 다시 그린 사본만 업로드.
- 고객 완료가 서버에 반영되면 SSE로 설계사 화면 갱신. 연결 장애 시 재연결·주기적 조회.
- 신분증 사본, 위임장, 동의서는 각각 별도 상태. 자필서명 미완료가 사본 준비를 막지 않음. 후속 확인에는 사유·담당자·시간 기록.
- 전자위임장 필수 단계 없음. 사전 출력·지참 요구 없음.

## 로컬 보안·보관
- 서버는 127.0.0.1에만 바인딩, Host/Origin 검사. 외부 공개·Netlify 함수 연결 없음.
- 요청별 256비트 무작위 토큰. 서버에는 해시만 보관. 링크의 토큰은 fragment로 전달하고 브라우저에서 주소창에서 제거해 탭 sessionStorage에 유지. 서버 접근은 헤더로 전달.
- 링크 유효시간 15분. 재발급 시 기존 링크 무효. 취소 후 완료 요청 거부. 중복 요청 키/상태 revision 검증.
- 고객에게는 병원·서류·사본 상태만 반환. 설계사는 본인 세션의 요청·사본만 접근. 다운로드 no-store, 공개 이미지 주소 없음.
- 가상 사본은 프로세스 메모리에만 보관. 직접 삭제 가능. 링크 만료 시 10초 주기 또는 다음 접근 시 삭제. 프로세스 종료 시 모든 요청·사본 소멸.
- 서버는 PNG 헤더·용량을 검사하지만, 가림의 적정성을 자동 판정하지 않음. 실제 고객·신분증·건강정보로 사용 금지.

## 검증
- `node --test tests/pro-preparation.test.mjs`: 소유권 분리, 최소 응답, 후속 상태 독립, 중복 완료·요청, 만료·재발급·취소·삭제 및 상태 충돌.
- `node tests/pro-browser.mjs`: 가상 고객→촬영 예시→마스킹→확인→설계사 실시간 반영, 360px·1280px 화면, 외부 세션 사본 접근 거부, 링크 재발급·취소.
- 픽셀 검사로 가림 영역이 불투명한 검정인지 확인. 고객 확인 전 서버 업로드가 0회인지 확인.
- 기존 앱 `node scripts/build.mjs` 프로덕션 빌드 성공. PRO는 `public/` 밖의 로컬 전용 소스와 화면으로 유지하여 기존 사이트 배포에 섞이지 않음.

## 실제 서비스 연결 전 남은 작업
기존 회원·확인된 담당자와 상담 소유권 연동, 운영 인증·HTTPS, 실제 발송 사업자와 동의/전달 실패 처리, 실제 병원별 요구정보·양식 확인, 확정된 개인정보 처리·보관·삭제 기준, 저장소 및 감사 기록 영속화와 운영 검증 필요. 이 MVP의 ‘가상 링크 준비’를 실제 발송 완료나 병원 접수 승인으로 해석하지 말 것.
