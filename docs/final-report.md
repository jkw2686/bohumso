## 구현
소비자 직접 선택만 허용합니다. 상담에서 가격·무료 이용권·단계별 주문·미결제 수락 제한을 제거했습니다.
상담 확정·완료·취소·분쟁은 광고 구독과 별개로 처리됩니다. 연락처는 기존 동의·역할 격리를 유지합니다.

새 ad_plans, ad_slots, ad_subscriptions, ad_impressions, ad_audit와 제한된 RPC를 사용합니다.
초기 세 요금제는 미정 조건을 NULL로 유지하고 비활성입니다. 관리자가 새 조건 버전을 저장하면 이전 버전 판매는 중지되며 기존 주문 조건은 바뀌지 않습니다.
광고 구독은 기간제 선불·수동 갱신입니다. 자동결제 빌링은 구현하지 않았습니다.
지역독점 슬롯 잠금, 중복 요청 키, 승인 키·금액 검증, 중복 승인 시 기간 유지, 환불 후 지연 승인 무시를 적용했습니다.
환불은 기간 종료·약정 노출 미달·관리자 플랫폼 귀책 근거가 있어야 요청할 수 있고 감사 이력을 기록합니다. 전액 환불만 구현했습니다.

광고 영역은 일반 목록과 분리해 표시합니다. 서버 서명 토큰, 10분 만료, 이벤트 중복 방지, 기본 비활성 수집 설정을 적용했습니다.
노출 집계는 실사용자 인증/봇 판별을 의미하지 않습니다. 운영 수준 부정 조회 방어는 추가 검토가 필요합니다.
