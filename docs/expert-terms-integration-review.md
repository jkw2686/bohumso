# 전문가 통합 약관·운영 검토안 — 2026-10-12

개발 검토 문서다. 현행 이용약관·개인정보처리방침을 교체하지 않았고 법률 검토가 완료된 것으로 표시하지 않는다. 공개 개방일·사업자 정보·상담료 취소 조건을 임의로 정하지 않았다.

## 동의와 재동의

- 설계사 개발 버전: `planner-protection-2026-10-12-v2`.
- 세무사 개발 버전: `tax-service-2026-10-12-v1`.
- 새 설계사 등록은 명시적 체크와 정확한 정책 버전을 서버에서 확인한다. 선택되지 않은 체크를 자동으로 켜지 않는다.
- `private.consent_records`의 EXPERT_TERMS 유형과 `expert_operating_principles` 출처를 재사용한다. 같은 계정·같은 버전의 중복 기록은 막고 기존 이력은 바꾸지 않는다.
- 기존 회원의 일반 프로필 수정은 새 동의를 강제하지 않는다. 본인이 새 원칙에 명시적으로 동의한 경우에만 새 기록을 남긴다.
- 기존 회원 전체에 새 의무·조치를 적용할지, 누구에게 어떤 설명과 고지·재동의를 받을지, 시행일은 운영·법률 검토 후 결정해야 한다. 이번 구현에 일괄 재동의 차단이나 자동 동의 처리는 없다.
- 현행 `public/expert-terms.html`, `public/terms.html`, 개인정보처리방침을 변경하지 않았다. 승인된 최종 문안·시행일 없이 이번 개발 동의 화면만 운영에 배포하면 안 된다.

## 향후 직역

변호사·손해사정사는 기존에 운영되는 경로를 닫지 않았고, 새 통합 경로로 가입·노출·과금을 개방하지 않았다. 향후 각각 자격·등록 확인, 업무 범위, 광고·업무 소개, 보수, 이해상충, 자료 보관·제공 조건을 별도 검토안으로 작성해야 한다. 현재 설계사 프로필을 해당 직역으로 바꾸거나 인증 표시를 추가하지 않았다.

## 대표 결정이 필요한 것

1. 세무사 가입·공개 및 통합 예약 개방 범위와 시점.
2. 신규 직군 플랫폼 이용료·무료기간·VAT·과금 시작일. 실제 결제 기능은 별도 작업.
3. 유료 세무 상담의 계약 당사자, 비용 고지·추가 업무 합의·취소·환불 절차.
4. 최종 운영 원칙과 약관 시행일, 기존 회원 공지·재동의 대상 및 절차.
5. 소비자 보호 위반 판정·집행·이의 신청과 기존 예약 보호 방안.
6. 등록 확인 자료의 보관·삭제 및 개인정보 제공 항목·동의 범위.
7. 첫 콘텐츠를 대표가 직접 검토한 뒤 운영 게시할지 여부.
