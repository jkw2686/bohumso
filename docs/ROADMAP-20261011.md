- `public/sw.js`(알림 전용, fetch 가로채기·캐시 금지) / 기존 manifest(아이폰은 홈 화면 추가 앱에서만)
- `private.push_subscriptions(user_id, endpoint unique, keys, device_label, confirmed_at, active, failure_count, last_success_at)` RLS·본인 RPC
- Netlify 함수 + web-push, VAPID 키 환경변수(생성까지만, 운영 등록은 멈춤 ②)
- 서버 이벤트 기준 발송(outbox → 서버 발송, 소비자 브라우저가 발송 호출 금지). `pg_net` 필요 시 운영 활성화는 멈춤 ② 항목,
  주기 실행이면 Netlify 사용량 추정. 404/410 → 구독 비활성. dedupe로 중복 금지.
- 알림 문구에 이름·연락처·주소·문의 본문 금지('새 상담 요청이 있어요', '새 방문 요청 · 4시간 안에 확인해 주세요').

**6-2 받는 사람**: 전문가(필수) 새 상담·방문 요청, 고객 일정 확정·변경·취소 / 대표(선택) 새 전문가 신청·안전·긴급 문의만 /
소비자(선택) 답변 도착·예약 확정·변경 — 요청·문의 직후 1회 제안, 거절 불이익 없음.

**6-3 노출 조건**: '확인된 구독 1개 이상'을 `planner_catalog`·`visit_catalog`·`expert_settings`(map/visit ON)에 추가.

- 팝업: '새 상담 요청을 놓치지 않도록 알림을 켜야 지도에 표시돼요' → [알림 켜기] → 허용 → 테스트 알림 → [받았어요] → 확인 완료.

- 모두 끊기면 지도·방문 후보 제외 + 프로필·업무 화면 맨 위 '알림 꺼짐 — 지도에서 숨겨졌어요 [다시 켜기]' + 다음 접속 팝업 + 관리자 목록.
