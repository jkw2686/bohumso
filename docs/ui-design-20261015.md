## 공통 시스템
- public/service-ui.css: 화이트 표면, 옅은 중립 배경, 16px 카드/12px 입력·버튼, 낮은 그림자, 48px 버튼/44px 최소 조작 영역, 16px 본문/14px 보조 설명, 180ms 색·테두리 전환.
- public/type-system.css에서 공통 스타일을 불러옵니다. 기존 Pretendard와 페이지 컴포넌트를 재사용하며 UI 프레임워크를 추가하지 않습니다.
- 주 버튼은 핵심 행동에 집중하고 보조 버튼은 테두리로 구분합니다. 포커스/오류/비활성/처리 중 상태를 표시하고 움직임 줄이기를 존중합니다.
- 기존 지도 높이·확대/위치·선택·예약 맥락을 유지합니다. 빈 지도 목록은 접힌 상태에서 핵심 안내만 표시하고 추가 행동은 펼치면 나타납니다.

## 화면 구성
- 홈: 제목/짧은 설명/주 행동 + 청구·가입보험 확인·전문가 지도·자료실 바로가기. 상황 선택 다음에 실제 지도를 배치. 회원가입 정보와 상세 서비스 설명은 후순위로 이동.
- 소비자 안내·자료실·로그인: 기존 경로와 펼침 기능 유지, 글자·여백·버튼 정리.
- 전문가: 프로필·상담 설정의 요약과 입력 영역을 구분. 저장 중 버튼/입력 잠금, 실패 시 상담 요청 받기 상태를 서버에 저장된 값으로 복구. 전화 입력 초안은 유지.
- 관리: 밝은 사이드 메뉴, 선택 메뉴만 브랜드색 강조. 기존 예약 지도·현황/필터/목록의 정보 구분 강화.
